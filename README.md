# AnyIpsum Homebrew Tap

Homebrew tap for [AnyIpsum](https://github.com/jodelamo/AnyIpsum), a macOS menu bar utility for generating lorem ipsum text.

## Install

```sh
brew tap jodelamo/anyipsum
brew install --cask jodelamo/anyipsum/anyipsum
```

## Update

```sh
brew upgrade --cask jodelamo/anyipsum/anyipsum
```

## Uninstall

```sh
brew uninstall --cask jodelamo/anyipsum/anyipsum
```

The cask installs the universal AnyIpsum application from the project's GitHub Releases. AnyIpsum currently publishes unsigned and unnotarized release artifacts, so macOS may require additional approval in Privacy & Security before the application can be opened.
